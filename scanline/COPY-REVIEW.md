# Copy review: BOTS.AI Scanline site

Approve, edit or strike each line below. Everything not listed here is your existing homepage copy, unchanged.

Three kinds of change:

1. **Edited:** your homepage line, reworded. The fact stays the same.
2. **Drafted:** new copy for the inner pages, built from facts already on your homepage. The source column names that fact.
3. **Confirm:** a statement only HR Anexi can verify. These need a yes before the site goes live.
